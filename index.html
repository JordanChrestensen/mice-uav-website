Autonomous Heavy-Lift UAV for Oil Spill Detection

Developing an autonomous UAV platform utilizing machine learning detection, precision navigation, and a custom sample collection payload.

Computer Vision

Powered by an NVIDIA Jetson Orin Nano running YOLOv8/v11 instance segmentation models for real-time oil spill detection.

Flight Control

Utilizing a Pixhawk 6X flight controller with MAVLink over Ethernet and Holybro RTK/GNSS for precision autonomous navigation.

Payload & Hardware

Custom CNC machined components and a 3D-printed water sampling payload integrated with SIYI camera gimbals.
